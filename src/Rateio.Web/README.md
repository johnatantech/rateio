# Rateio.Web

App Angular do Rateio. Veja o [README principal](../../README.md) para a visão geral do projeto.

```bash
npm ci
npm start          # http://localhost:4200, com /api encaminhado para a API em http://localhost:5080
npm run test:ci    # testes unitários com Vitest
npm run build      # build de produção em dist/
```
